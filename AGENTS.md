# Agents — create-concorde-ts-starter

Concorde project template (Lit + TypeScript web components, `@supersoniks/concorde`).

## Skill

The `concorde` skill (store, `DataProviderKey`, decorators, HTTP, lists, forms, styling, composition; topic files in `rules/`) is installed in `.agents/skills/` (Cursor, Codex…) and linked from `.claude/skills/` (Claude Code) and `.junie/skills/` (JetBrains Junie). These folders are not versioned: `npx @supersoniks/create-concorde-ts-starter` installs them, and after a clone or a Concorde upgrade run:

```bash
yarn ai:sync
```

It comes from `@supersoniks/concorde/ai/` (or `../concorde/ai` when the Concorde repository sits next to this one). Do not edit the copies.

## Project

Deliberately minimal: three routes and one demo component.

- `src/app/` — file-based routes: `layout.ts` (header: brand, nav, light / dark), `page.ts` (`/`), `demo/page.ts` (`/demo`), `404.ts`. `router.ts` is generated by `autoRoutesPlugin("src/app")`; do not edit it. Every folder here is a route (no hyphens), so components go in `src/components/`.
- `src/components/flight-board.ts` — reference component: form fields write to a `DataProviderKey` store entry, `@subscribe` reads it, `sonic-list` renders.
- `src/components/theme-toggle.ts` — sets `data-theme` on `<html>`; tokens for both modes are in `src/css/app.css`.
- `yarn dev` (https, port 3000; `STARTER_HTTP=1` for plain http) · `yarn build` (`tsc` + Vite).
